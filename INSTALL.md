# Quick Installation Guide

## Install the Extension (2 minutes)

### Step 1: Open Chrome Extensions
1. Open Google Chrome
2. Type `chrome://extensions/` in the address bar and press Enter
3. Or: Click the three dots menu → Extensions → Manage Extensions

### Step 2: Enable Developer Mode
- Look for the toggle switch labeled **"Developer mode"** in the top-right corner
- Click it to turn it ON (it should turn blue)

### Step 3: Load the Extension
1. Click the **"Load unpacked"** button (appears after enabling Developer mode)
2. Navigate to: `C:\Users\wgshx\claim-autofill-extension`
3. Click **"Select Folder"**

### Step 4: Pin the Extension (Optional but Recommended)
1. Click the puzzle piece icon 🧩 in your Chrome toolbar
2. Find "Claim Amount Auto-Fill" in the list
3. Click the pin icon 📌 next to it

## Done! 🎉

The extension is now installed and ready to use.

## Test It Out

1. Open any webpage with claim forms
2. The extension will automatically fill empty approved amounts
3. Click the extension icon to:
   - Toggle auto-fill on/off
   - Manually trigger filling with "Fill Now" button

## Troubleshooting

**Can't see the extension?**
- Make sure Developer mode is enabled
- Check that you selected the correct folder
- Try refreshing the page

**Extension not working?**
- Refresh the webpage (Ctrl+R or Cmd+R)
- Check that auto-fill is enabled (click extension icon)
- Click "Fill Now" to manually trigger
