# Important Safety and Release Notes

- Current release: **1.11.0**.
- Editable source files are at the repository root.
- `dist/` and `claim-autofill-extension.zip` are generated by
  `npm run build`; do not edit them.
- Load `dist/` for local development or the extracted release ZIP for a
  controlled user installation.
- The current package connects to the `claimextension` development Firebase
  project. It is not the production Firebase release.
- Opening a page, signing in, or refreshing a licence never writes portal
  fields.
- Preview is read-only. Apply is explicit. Undo and recovery remain local.
- Never use real patient or claim information in screenshots, fixtures,
  support messages, cloud logs, or test records.
- Production deployment and Chrome Web Store publication require the Phase 4
  gates in `BLUEPRINT.md`.
